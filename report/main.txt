\textbf{Abstract}\\
In this practice we study the statistical behavior of a system of $N$ independent, unbiased coins as a simple model for two-state physical systems. Using Python, we write a modular program to list all microstates for small $N$, test the computational and memory limits of full state enumeration up to a 5-minute runtime limit, and use the log-gamma function to compute macrostate multiplicities $\Omega(N,k)$ for larger systems ($N = 20, 50, 80, 100$) without floating-point overflow. \section{Introduction and Objectives}

The goal of this laboratory practice is to study the connection between the microscopic configurations of a system and its macroscopic behavior using a set of $N$ unbiased coins. Even though tossing coins is a basic probability problem, it is mathematically equivalent to many two-state systems in statistical physics, such as an ideal paramagnet of $N$ non-interacting spin-$1/2$ particles in zero external magnetic field or a binary lattice gas.

For a system of $N$ independent, unbiased coins, each coin has two equally likely outcomes: heads ($\mathrm{H}$) or tails ($\mathrm{T}$), each with probability $p = 1/2$. We distinguish between two descriptions of the system:
\begin{itemize}
    \item \textbf{Microstate:} The exact sequence of heads and tails for all $N$ coins in order (for example, $\texttt{HHTHT}$ for $N=5$). Since each of the $N$ coins has 2 possibilities, the total number of microstates is:
    \begin{equation}
        \Omega_{\mathrm{total}}(N) = 2^N.
    \end{equation}
    \item \textbf{Macrostate:} A state defined only by a macroscopic observable, which in this case is the total number of heads $k$ (and $N-k$ tails), regardless of the order in which they appear.
\end{itemize}

The number of distinct microstates that correspond to the same macrostate $k$ is called the multiplicity $\Omega(N,k)$, given by the binomial coefficient:
\begin{equation}
    \Omega(N,k) = \binom{N}{k} = \frac{N!}{k!\,(N-k)!}.
    \label{eq:binomial}
\end{equation}
Summing the multiplicities over all possible values of $k$ from $0$ to $N$ gives the total number of microstates via the binomial expansion:
\begin{equation}
    (1 + 1)^N = \sum_{k=0}^{N} \binom{N}{k} = \sum_{k=0}^{N} \Omega(N,k) = 2^N.
\end{equation}
Since all microstates are equally likely with probability $2^{-N}$, the probability of observing the macrostate with $k$ heads is:
\begin{equation}
    P_k = \frac{\Omega(N,k)}{2^N}.
    \label{eq:prob}
\end{equation}
Finally, the macroscopic thermodynamic entropy $S$ of a macrostate is linked to its multiplicity through Boltzmann's equation:
\begin{equation}
    S(N,k) = k_B \ln \Omega(N,k),
    \label{eq:boltzmann}
\end{equation}
where $k_B = 1.380649 \times 10^{-23}\text{ J/K}$ is the Boltzmann constant.

\subsection{Maximum Computable $N$ for Full Enumeration (Part 1b)}
Enumerating every microstate requires visiting all $2^N$ configurations, so the execution time always scales exponentially as $\mathcal{O}(2^N)$. Every time we add just one more coin ($N \to N+1$), the number of states and the runtime double. However, what stops the program first depends on how we handle memory:

\begin{enumerate}
    \item \textbf{Memory limit when storing all states in a list:} If a program stores all $2^N$ states in RAM at the same time (for instance, a Python list of strings or integers), the memory required grows as $\mathcal{O}(2^N)$. Even storing a single 8-byte 64-bit integer per state requires $8 \times 2^{30} \approx 8.59\text{ GB}$ at $N = 30$ and $17.18\text{ GB}$ at $N = 31$ (and storing Python strings crashes even earlier, around $N = 27\text{--}28$, because each string object takes over 50 bytes in Python). On a standard 16 GB laptop, in-memory enumeration hits a hard RAM wall at $N = 30$.
    \item \textbf{CPU time limit when using generators and chunked bitwise shifts:} To avoid running out of RAM, we wrote \texttt{iter\_microstates(N)} as a Python generator using \texttt{yield}. Because it generates one integer at a time and discards it before moving to the next, its memory usage is $\mathcal{O}(1)$ (under 1 MB for any $N$). Similarly, our \texttt{fast\_bitwise\_counts(N)} function processes states in fixed blocks of $2^{24}$ integers ($\approx 128\text{ MB}$ of RAM) using NumPy bitwise right-shifts \texttt{(chunk >> bit) \& 1}. With memory no longer a bottleneck, the only limitation is the 5-minute ($300\text{ s}$) wall-clock time limit.
\end{enumerate}

Table~\ref{tab:scaling} shows the measured execution times and memory usage on our system. Within the 5-minute cutoff:
\begin{itemize}
    \item The pure-Python \texttt{yield} generator processes about $2.45 \times 10^7\text{ states/s}$ and reaches a maximum of $\mathbf{N_{\max} = 32}$ ($4.29 \times 10^9$ states in $175.3\text{ s}$, whereas $N = 33$ takes $\approx 351\text{ s}$).
    \item The chunked NumPy bitwise loop processes about $5.0 \times 10^8\text{ states/s}$ and reaches $\mathbf{N_{\max} = 37}$ ($1.37 \times 10^{11}$ states in $274.8\text{ s}$, whereas $N = 38$ takes $\approx 550\text{ s}$).
\end{itemize}

\subsection{Macrostate Distributions for $N = 20, 50, 80, 100$ (Part 1c)}
For $N \ge 50$, enumerating individual microstates is impossible, so we compute $\Omega(N,k)$ directly from the binomial formula. To avoid overflow when calculating large factorials, we evaluate the natural logarithm of $\Omega(N,k)$ using Euler's log-gamma function (\texttt{scipy.special.gammaln}), since $\Gamma(n+1) = n!$:
\begin{equation}
    \ln \Omega(N,k) = \ln\Gamma(N+1) - \ln\Gamma(k+1) - \ln\Gamma(N-k+1).
    \label{eq:gammaln}
\end{equation}
From $\ln\Omega(N,k)$, the macrostate probability is obtained safely as:
\begin{equation}
    P_k = \exp\bigl(\ln\Omega(N,k) - N\ln 2\bigr),
\end{equation}
and the base-10 multiplicity for log-scale plotting is $\Omega(N,k) = 10^{\ln\Omega(N,k)/\ln 10}$.

Our script \texttt{main.py} generates the two-panel figure \texttt{report/figures/macrostate\_distributions.pdf} showing $P_k$ (linear scale) and $\Omega(N,k)$ (logarithmic scale) as a function of $k$ for $N = 20, 50, 80,$ and $100$. Table~\ref{tab:dist_values} summarizes the main features of the four curves. As $N$ increases from 20 to 100, the total number of microstates grows from $1.05 \times 10^6$ to $1.27 \times 10^{30}$, the peak multiplicity $\Omega(N, N/2)$ reaches $1.0089 \times 10^{29}$ at $k = 50$ for $N = 100$, and the relative width of the peak ($\sigma/\mu = 1/\sqrt{N}$) becomes progressively narrower.

\subsection{Maximum Computable $N$ for the Distribution (Part 1d)}
The maximum value of $N$ for which we can calculate and plot the macrostate distribution depends on which numerical method is used:
\begin{enumerate}
    \item \textbf{Direct factorial evaluation ($N!$ in 64-bit float):} Standard IEEE 754 double-precision floats (\texttt{float64}) have a maximum representable value of $D_{\max} \approx 1.7977 \times 10^{308}$. Computing $N!$ directly in floating point overflows at $\mathbf{N = 171}$ because $170! \approx 7.26 \times 10^{306}$, while $171! \approx 1.24 \times 10^{309} > D_{\max}$.
    \item \textbf{Direct multiplicity $\Omega(N,k)$ in 64-bit float:} Even if we avoid intermediate factorials, the peak binomial coefficient $\Omega(N, N/2) \approx 2^N / \sqrt{\pi N / 2}$ itself exceeds $1.7977 \times 10^{308}$ once $N \ge 1030$. Specifically, $\Omega(1029, 514) \approx 1.43 \times 10^{308}$ fits in a 64-bit float, whereas $\Omega(1030, 515) \approx 2.86 \times 10^{308}$ overflows to \texttt{inf}. Thus, if plotting $\Omega(N,k)$ directly as standard floats, the hard limit is $\mathbf{N_{\max} = 1029}$ (and $2^N$ overflows at $N = 1024$).
    \item \textbf{Log-space evaluation using \texttt{gammaln}:} When computing $\ln\Omega(N,k)$ and $P_k = \exp(\ln\Omega - N\ln 2)$ via Eq.~\eqref{eq:gammaln}, the logarithm $\ln\Omega(N, N/2) \approx N\ln 2$ never overflows \texttt{float64} for any realistic $N$. Instead, calculating and plotting the full array $k = 0, 1, \dots, N$ is limited by \textbf{RAM and array size}: since the array has $N+1$ elements, storing three \texttt{float64} arrays ($k$, $\ln\Omega$, and $P_k$, taking 24 bytes per $k$) on a 16 GB laptop limits full-range plotting to roughly $\mathbf{N \sim 5 \times 10^8}$. Furthermore, if we only evaluate points near the peak $N/2$, double-precision floating-point subtraction in Eq.~\eqref{eq:gammaln} loses its 53 bits of mantissa precision ($\epsilon \approx 1.1 \times 10^{-16}$) to catastrophic cancellation around $\mathbf{N \sim 10^{15}}$.
\end{enumerate}

\subsection{Extrapolation to the Thermodynamic Limit ($N \sim 10^{23}$, Part 1e)}
When the number of elements scales up to macroscopic Avogadro-scale numbers ($N \sim 10^{23}$), we can apply Stirling's approximation $\ln(n!) \approx n\ln n - n + \frac{1}{2}\ln(2\pi n)$ to $\ln\Omega(N,k)$ and expand around the peak $k = N/2$ in powers of the deviation $\delta = k - N/2$ (with $|\delta| \ll N$). Keeping the leading quadratic term gives the Gaussian (normal) distribution:
\begin{equation}
    P(k) = \frac{\Omega(N,k)}{2^N} \approx \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(k - \mu)^2}{2\sigma^2}\right),
    \label{eq:gaussian}
\end{equation}
where the mean and standard deviation are:
\begin{equation}
    \mu = \frac{N}{2}, \qquad \sigma = \frac{\sqrt{N}}{2}.
\end{equation}

For a macroscopic system with $N = 10^{23}$ coins:
\begin{itemize}
    \item The mean is $\mu = 5 \times 10^{22}$ heads and the absolute standard deviation is $\sigma = \sqrt{10^{23}}/2 \approx 1.58 \times 10^{11}$ heads. Although $10^{11}$ coins is a large absolute number, it is tiny compared to $5 \times 10^{22}$.
    \item The \textbf{relative fluctuation} around the mean is:
    \begin{equation}
        \frac{\sigma}{\mu} = \frac{\sqrt{N}/2}{N/2} = \frac{1}{\sqrt{N}} = \frac{1}{\sqrt{10^{23}}} \approx 3.16 \times 10^{-12}.
    \end{equation}
    \item Because the relative width shrinks as $1/\sqrt{N} \to 0$, if we plot the distribution against the macroscopic fraction of heads $x = k/N \in [0, 1]$, the curve collapses into an extremely sharp spike (a Dirac delta function $\delta(x - 1/2)$) centered at $x = 0.5$. Any noticeable macroscopic deviation from $50\%$ heads and $50\%$ tails has a probability that is exponentially close to zero. This explains why macroscopic thermodynamic averages appear completely constant and deterministic in equilibrium.
\end{itemize}

\section{Probabilities, Entropy, and Thermodynamics}

\subsection{Group Parameter $N = 100 + M$}
According to the lab instructions, $M$ is the harmonic mean of the last two digits of the team members' NIAs ($36, 45, 60,$ and $75$):
\begin{equation}
    M = \frac{4}{\frac{1}{36} + \frac{1}{45} + \frac{1}{60} + \frac{1}{75}} = \frac{4}{\frac{25 + 20 + 15 + 12}{900}} = \frac{4}{72 / 900} = 50.
\end{equation}
Therefore, our system has:
\begin{equation}
    N = 100 + M = 150\text{ coins}, \qquad \frac{N}{2} = 75, \qquad 2^{150} = 1.4272 \times 10^{45}\text{ total microstates}.
\end{equation}

\subsection{Probability Calculations (Parts 2a--2d)}
Using our functions \texttt{prob\_k} and \texttt{cumulative\_prob} for $N = 150$:
\begin{itemize}
    \item \textbf{a) Probability of $k = 30$ heads:}
    \begin{equation}
        \Omega(150, 30) = 3.2202 \times 10^{31}, \qquad P_{30} = \frac{\Omega(150, 30)}{2^{150}} = 2.2562 \times 10^{-14}.
    \end{equation}
    \item \textbf{b) Probability of $k = N/2 = 75$ heads (most probable macrostate):}
    \begin{equation}
        \Omega(150, 75) = 9.2826 \times 10^{43}, \qquad P_{75} = \frac{\Omega(150, 75)}{2^{150}} = 0.065039 \;\; (6.5039\%).
    \end{equation}
    \item \textbf{c) Cumulative probability between $k_1 = N/2 - 10 = 65$ and $k_2 = N/2 + 10 = 85$ heads:}
    \begin{equation}
        \Delta P_{65, 85} = \sum_{k=65}^{85} P_k = 0.913931 \;\; (91.3931\%).
    \end{equation}
    \item \textbf{d) Cumulative probability between $k_1 = N/2 - 20 = 55$ and $k_2 = N/2 + 20 = 95$ tails:}
    Since the coins are unbiased, the probability distribution for tails is identical to that for heads ($\Omega(N, N-k) = \Omega(N, k)$):
    \begin{equation}
        \Delta P_{55, 95} = \sum_{k=55}^{95} P_k = 0.999242 \;\; (99.9242\%).
    \end{equation}
\end{itemize}

\subsection{Entropy Changes $\Delta S_{k_1 k_2}$ (Parts 2e--2g)}
Using Boltzmann's formula $S(k) = k_B \ln \Omega(N,k)$, the entropy difference between two macrostates $k_1$ and $k_2$ is:
\begin{equation}
    \Delta S_{k_1 k_2} = S(k_1) - S(k_2) = k_B \bigl[\ln\Omega(N, k_1) - \ln\Omega(N, k_2)\bigr] = k_B \ln\!\left(\frac{\Omega(N, k_1)}{\Omega(N, k_2)}\right).
    \label{eq:delta_s}
\end{equation}
For $N = 150$, we obtain:
\begin{itemize}
    \item \textbf{e) $k_1 = N/2 + 25 = 100$ (high disorder) and $k_2 = N/2 = 75$ (maximum disorder):}
    \begin{equation}
        \frac{\Delta S_{100, 75}}{k_B} = 92.8030 - 101.2393 = -8.4363, \qquad \Delta S_{100, 75} = -1.1648 \times 10^{-22}\text{ J/K}.
    \end{equation}
    \item \textbf{f) $k_1 = N/2 + 10 = 85$ (moderate disorder) and $k_2 = N/2 = 75$ (maximum disorder):}
    \begin{equation}
        \frac{\Delta S_{85, 75}}{k_B} = 99.9109 - 101.2393 = -1.3284, \qquad \Delta S_{85, 75} = -1.8340 \times 10^{-23}\text{ J/K}.
    \end{equation}
    \item \textbf{g) $k_1 = N/2 = 75$ (maximum disorder) and $k_2 = 20$ (high order):}
    \begin{equation}
        \frac{\Delta S_{75, 20}}{k_B} = 101.2393 - 56.5513 = +44.6880, \qquad \Delta S_{75, 20} = +6.1699 \times 10^{-22}\text{ J/K}.
    \end{equation}
\end{itemize}
Notice that $\Delta S$ is negative in (e) and (f) because $S(k_1) < S(k_2)$ when comparing a less disordered state ($k_1 = 100$ or $85$) to the maximum-entropy state ($k_2 = 75$), whereas $\Delta S$ is positive in (g) because $k_1 = 75$ has a much larger multiplicity than the highly ordered state $k_2 = 20$. \subsection{Thermodynamic Implications (Parts 2h--2k)}

\textbf{h) Waiting Time for a Highly Ordered State ($k = 8$ heads):}\\
For $k = 8$ heads out of $N = 150$ coins, the multiplicity and single-trial probability are:
\begin{equation}
    \Omega(150, 8) = \binom{150}{8} = 5.2572 \times 10^{12}, \qquad P_8 = \frac{\Omega(150, 8)}{2^{150}} = 3.6835 \times 10^{-33}.
\end{equation}
Tossing $N$ coins per second means we perform $1$ complete trial of $N = 150$ coins every second ($\tau_0 = 1\text{ s}$). The expected number of trials needed to observe $k = 8$ heads is $1/P_8$, giving an expected waiting time of:
\begin{equation}
    \langle t \rangle = \frac{1\text{ s}}{P_8} = 2.7148 \times 10^{32}\text{ s} \approx 8.6028 \times 10^{24}\text{ years}.
\end{equation}
Since the age of the universe is roughly $1.38 \times 10^{10}\text{ years}$, it would take about $6.23 \times 10^{14}$ times the age of the universe to randomly see 8 heads. (Even if the rate were interpreted as 150 full trials per second, the waiting time would still be $5.735 \times 10^{22}\text{ years}$.)

\textbf{i) Likelihood Ratio:}\\
To quantify how much more likely it is to obtain the most probable macrostate ($k = N/2 = 75$) compared to $M \pm 10 = 50 \pm 10$ heads ($k = 40$ and $k = 60$), we take the ratio of their probabilities:
\begin{align}
    \frac{P_{75}}{P_{40}} &= \frac{\Omega(150, 75)}{\Omega(150, 40)} = 2.1059 \times 10^7 \quad (\text{21.06 million times more likely}), \\
    \frac{P_{75}}{P_{60}} &= \frac{\Omega(150, 75)}{\Omega(150, 60)} = 20.0854 \quad (\text{20.09 times more likely}).
\end{align}
If we also compare $k = 75$ against $N/2 \pm 10 = 75 \pm 10$ ($k = 65$ or $85$), the ratio is:
\begin{equation}
    \frac{P_{75}}{P_{85}} = \frac{\Omega(150, 75)}{\Omega(150, 85)} = \exp(1.3284) = 3.7749 \quad (\text{3.775 times more likely}).
\end{equation}

\textbf{j) Second Law of Thermodynamics Interpretation:}\\
None of these results contradict the Second Law of Thermodynamics. The Second Law states that the entropy of an isolated macroscopic system tends to increase toward its maximum ($\Delta S \ge 0$), but from a statistical physics viewpoint, this law is probabilistic rather than strictly mechanical. From Eq.~\eqref{eq:delta_s}, the probability of observing a state $k_1$ relative to the maximum-entropy equilibrium state $k_2 = N/2$ is:
\begin{equation}
    \frac{P(k_1)}{P(k_2)} = \exp\!\left(\frac{\Delta S_{k_1 k_2}}{k_B}\right).
\end{equation}
When $N$ is small ($N = 150$), a fluctuation to a slightly more ordered state with $\Delta S < 0$ (such as $k = 85$, where $\Delta S = -1.3284\,k_B$) still has a relatively large probability ($P_{85}/P_{75} = e^{-1.3284} \approx 0.265$), so small fluctuations away from maximum entropy happen frequently. However, for a macroscopic system ($N \sim 10^{23}$), any measurable macroscopic decrease in entropy scales extensively as $\Delta S \propto -N k_B$, making the probability $\exp(-c N) \sim \exp(-10^{23})$ practically zero. Therefore, finite-$N$ fluctuations are completely consistent with statistical mechanics, while the Second Law holds without exception at the macroscopic scale.

\textbf{k) Re-evaluation in the Large-$N$ Limit ($N \sim 10^{23}$ or $N \to \infty$):}\\
If we scale the system to $N \sim 10^{23}$ (or take $N \to \infty$), the quantities in parts (a)--(j) behave as summarized in Table~\ref{tab:large_n}:
\begin{itemize}
    \item \textbf{Single-state probabilities (2a, 2b):} For a fixed number of heads like $k = 30$ (or a fixed fraction $k = 0.2N$), $P_k \to 0$ exponentially as $2^{-N}$. Even at the peak $k = N/2$, the probability of hitting that single exact integer is $P_{N/2} \approx \sqrt{2/(\pi N)} \approx 2.52 \times 10^{-12} \to 0$ because the probability is spread across $\sigma \sim 10^{11}$ neighboring states.
    \item \textbf{Cumulative intervals (2c, 2d):} If the interval width is kept fixed at $\pm 10$ or $\pm 20$ individual coins, the interval becomes much narrower than $\sigma = \sqrt{N}/2 \approx 1.58 \times 10^{11}$, so $\Delta P \approx 21 \times P_{N/2} \approx 5.30 \times 10^{-11} \to 0$. Conversely, if the interval is defined as a macroscopic percentage around $N/2$ (such as $0.5N \pm 0.001N$), then $\Delta P \to 1$ ($100\%$).
    \item \textbf{Entropy changes (2e, 2f, 2g):} Using the Gaussian approximation $\ln\Omega(N, N/2 + \delta) - \ln\Omega(N, N/2) \approx -2\delta^2/N$, a fixed microscopic offset $\delta = +25$ or $\delta = +10$ gives $\Delta S / k_B \approx -2\delta^2/N \to 0$ ($-1.25 \times 10^{-20}$ and $-2.0 \times 10^{-21}$ at $N = 10^{23}$). If instead the offset is a fixed macroscopic fraction $\delta = \alpha N$, then $\Delta S / k_B \propto -N \to -\infty$. For part (2g), $\Delta S_{N/2, 20}/k_B \approx N\ln 2 \approx +6.93 \times 10^{22} \to +\infty$ ($\Delta S \approx +0.957\text{ J/K}$).
    \item \textbf{Waiting time and likelihood ratios (2h, 2i, 2j):} For $k = 8$ heads, the waiting time diverges as $\langle t \rangle \sim 2^N / N^8 \sim 10^{3.01 \times 10^{22}}\text{ s} \to \infty$. The likelihood ratio relative to any fixed ordered state ($k = 40$ or $60$) diverges to $\infty$, whereas for a microscopic shift of $\pm 10$ coins around $N/2$, $P_{N/2}/P_{N/2 \pm 10} \approx \exp(200/N) \to 1$. Macroscopic violations of the Second Law have zero probability.
\end{itemize}

\section{Conclusion}

In this practice we analyzed the microstates and macrostates of an $N$-coin binary system both numerically and analytically. For small $N$, bitwise representations and Python generators allowed us to iterate through $2^N$ states in $\mathcal{O}(1)$ memory, reaching $N = 32$ with a pure-Python generator and $N = 37$ with chunked NumPy bit-shifting within the 5-minute time limit. For larger $N$, evaluating $\ln\Omega(N,k)$ with the log-gamma function avoided the 64-bit float overflow limits at $N = 171$ ($N!$) and $N = 1030$ ($\Omega(N, N/2)$). Finally, our calculations for $N = 150$ and $N \sim 10^{23}$ showed how the narrowing of relative fluctuations ($\sigma/\mu = 1/\sqrt{N}$) and Boltzmann's entropy formula $S = k_B \ln\Omega$ explain the statistical origin of the Second Law of Thermodynamics.
